# DustRoute

[English](README.md) · [日本語](README.ja.md)

DustRouteは、AIとプレイヤーが一緒にMinecraftのレッドストーン回路や対応する建築物を
調べ、試作し、建築するためのツールです。現地を観測し、モデル上で変更を試し、
計画を確認してから、承認した作業を実行・照合します。

MCPに接続したAIへ、例えば次のように依頼できます。

> この回路を説明して、分からないことも教えて。

> 世界を変更する前に、リピーターの遅延を変えた案と比較して。

> botのインベントリにある材料で、この採用済み設計図を建てて。
> まず建築手順と仮設ブロックを見せて。

## できること

| 目的 | 現在の範囲 |
| --- | --- |
| 回路を理解する | 視線・領域の観測、接続、診断、範囲を限定した機能解析 |
| 別案を試す | 不変の仮想Revisionと、実世界への反映前のモデル検証 |
| 設計を再利用する | 設計図の部品・型・要求、更新提案の検証、Assemblyの採用 |
| 機構を設置する | 対応レッドストーン、方向混在ピストン、型付きドア、有限飛行機構 |
| 建築物を設計する | 明示した部品、開口、空間、対応設備との合成 |
| サバイバルで建てる | 範囲を限定した受動的な立方体建材、支給材料、仮設、撤去・退避 |

条件と未対応事項は[対応表](docs/capabilities.ja.md)を参照してください。
観測・シミュレーション・施工の対応範囲は異なります。
ブロックを認識できても、そのブロックへの全操作が使えるとは限りません。

## 始めるには

1. [導入ガイド](docs/getting-started.ja.md)で接続と権限を確認します。
2. [利用手順](docs/workflows.ja.md)から観測・設計・建築の流れを選びます。
3. [文書案内](docs/README.ja.md)からAPI仕様と検証証拠へ進めます。

実接続には同梱のRustライブラリVoxrigを使います。
現在のMCP接続はMinecraft Java 1.21.11・オフライン認証が対象です。
通常のブロック観測は受信パケットと対応するクライアント再現を使い、
サーバーMODやセルごとのコマンド照合は不要です。Mineflayerと製品CLIは撤去済みです。

コマンドによる回路・Assembly配置にはOP権限が必要です。
別経路の対応サバイバル建築は、所持品と通常のプレイヤー操作を使い、OP不要です。
実世界の変更は既定で無効です。どちらも対応するポリシーと明示的な確認が必要です。

モデル検証は記録したコンテキストで宣言した要求を確認します。
実機検証は新しい観測を照合します。世界の凍結やサーバー内部の予約が空であることは
証明しません。任意ブロック、エンティティへの作用、制限のない地形編集、
汎用の完全自律設計は現在の範囲外です。
