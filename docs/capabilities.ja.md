# 現在の対応範囲

[English](capabilities.md) · [日本語](capabilities.ja.md)

基準は2026-10-05に集約したdevelopです。全内部APIではなく、公開利用経路と条件を
まとめています。[概要](../README.ja.md)から読み、目的が決まったら[利用手順](workflows.ja.md)へ
進んでください。詳細資料は英語を標準とします。

## できることと境界

| 分野 | できること | 制約・未対応 |
| --- | --- | --- |
| 観測 | 視線、選択領域、明示座標からブロック名・状態・証拠を取得 | チャンク不足、未対応の状態再現・視線形状などで拒否。サーバー内部イベントは観測できない。[仕様](mcp-public-features.md#observation-backends) |
| 回路解析 | 接続、信号方向、物理階層、論理式、要求時の範囲を限定した真理値表 | 任意の大規模回路の完全解析。途中結果・予算切れは証明にならない。[仕様](physical-function-model.md) |
| 仮想編集 | 追加・撤去・属性変更、不変Revision、分岐、シミュレーション、スコープ付き保存 | Revisionのマージ、通常の回路Revisionの無期限保持。[仕様](circuit-revisions.md) |
| 電気シミュレーション | ダスト、リピーター、比較器、トーチ、オブザーバーなどの登録済み挙動 | 全ブロック・全状態、全ケースでの実機時刻一致。クライアントframeはサーバーtickではない。[仕様](world-execution-context.md) |
| ピストン | 6方向の共通runtime、混在時の相互作用、導体給電、準接続 | 未登録の移動・破壊挙動、エンティティへの作用。[仕様](custom-piston-assembly-placement.md) |
| 粘着・形状・支持 | スライム／ハチミツの分岐と共通12ブロック制限、対応する乾いたハーフブロック・階段、部品の支持喪失 | 全材質、水没、板ガラス、エンティティの粘着。[粘着](piston-adhesion.md)、[階段](stairs-runtime-readback.md)、[支持](support-loss-runtime.md) |
| ピストンドア | 固定1×2の設置・認識・開閉、参照3×3の型検証・配置・撤去 | 任意ドアの認識、汎用3×3実機操作・完了判定ツール。[1×2](piston-door-mcp-v1.md)、[3×3](piston-door-type.md) |
| フライングマシン | 登録済み2エンジン系統、有限飛行の生成・採用・空きコース配置・到着診断・撤去 | 新エンジンの発明、無制限の追従、反復走行、乗員・荷物。生成器の距離は1〜16ブロック。[仕様](flying-machine-generation.md) |
| 作物 | 宣言した成熟カボチャ・スイカの破壊、固定した対応環境でのサトウキビ破壊・支持喪失のモデル化 | 成長、水流、回収、継続農業。サトウキビ機体例はモデル・MCP回帰までで、新しいJava実機比較は未実施。[仕様](existing-machine-modification.md) |
| 設計図 | 固定参照の部品・型・端子・要求、明示した更新提案、再検証・採用、永続カタログ | 採用だけでMinecraftを書き換えること、過去の合格を現在の証拠として扱うこと。[仕様](blueprint-mcp.md) |
| 建築設計 | 名前付き形状、切抜き、厳密な空間、採用済み設備Assembly一つとの合成。設備内部には複数機構を含められる | 生成器は6種類の立方体建材・最大256非Airブロック。汎用地形撤去・設備の自動配線は未対応。[仕様](blueprint-building-design.md) |
| コマンド配置 | 対応組込み回路・採用済みAssembly・観測元Revisionの編集、設置順・プレビュー・読戻し・条件付き復旧 | OPコマンド権限と変更ポリシー、完全な新しい観測が必要。新規Assembly配置はガードを含む空き領域が必要。[仕様](mcp-public-features.md#execution-and-recovery) |
| 区画作業 | 観測元Revisionの分割、全コンテキストでの段階検証、進捗診断、再起動後の前進・逆順作業の再計画 | 最大64段階×64変更、非Air・仮想編集の各4,096上限内。結合が強い場合は区画・中間設計の変更が必要。[仕様](large-circuit-regions.md) |
| サバイバル建築 | 公開ツールでの所持品を使う計画・施工、仮設、移動、撤去、退避、安全に封じたcheckpointからの継続。非OPのbot一体で動作 | 乾いた受動的な属性なし立方体と明示した編集・移動・仮設範囲。能動回路の施工、チェスト補給、資源採取、任意地形は未対応。[仕様](survival-public-construction.md) |
| 診断・修復 | 回路の問題、設計との差分、対応する修復・再構築案 | 任意故障の復旧、原因・所有者の証明。Assembly再構築は現在、撤去して建て直す方式。[仕様](assembly-diagnosis.md) |
| 最適化 | 端点固定・分岐なしダスト経路、互換macro置換、型を保つ有限予算のブロック数探索 | 汎用の全体最適化、最小ブロック数の保証。[仕様](blueprint-block-reduction.md) |
| 再起動・取消し | 定義・履歴の永続化、再観測と新規計画、サバイバルの封じたアイドルcheckpointからの継続 | 任意クラッシュ復旧、失われたnative操作の再送、無条件rollback。多くの実行計画は再起動で失効。[仕様](mcp-public-features.md#execution-and-recovery) |
| 接続 | 同梱Voxrig、Java 1.21.11、オフライン認証。通常観測と対応サバイバル操作はMOD不要 | オンライン認証、他版へのMCP実接続。コマンドプレビュー・接近・施工には各権限が必要。[仕様](../crates/dustroute-mcp/SETUP.md) |

観測可能な範囲、モデルが受理する範囲、公開操作で実行できる範囲は異なります。
ピストンのシミュレーション・Assembly配置への対応は、
すべての遷移試験ツールでピストンを扱えるという意味ではありません。

## 実機で確認した範囲

| 証拠 | 宣言した試験の結果 | 意味 |
| --- | --- | --- |
| [2026-10-05のnative設計図・区画試験](blueprint-iteration-live-validation.md) | 作成・検証・採用・配置・編集・取消し・撤去・プロセス再起動。MCP呼出し95件、想定拒否13件、独立セル照合106,552件、領域復元 | 内部JSON除去後の有限な利用経路の新しい証拠。全回路物理の証明ではない |
| [2026-10-03のサバイバル試験](survival-public-construction.md#verification) | 公開経路で非OPの屋根施工115手順、仮設18個の撤去・退避。配置・採掘checkpoint後に別プロセスで継続 | 有限範囲の施工・封じたcheckpointの継続。任意クラッシュ復旧ではない |
| [ドア試験](reference-door-live-construction.md)・[飛行試験](flying-machine-lifecycle.md) | 記録した設置、動作・到着、診断、撤去ケース | 当時の版・backend条件の証拠。保存した観測は履歴であり、新しい実行権限ではない |

モデル合格は、記録した条件下で宣言した要求を満たしたことを示します。
実機の読戻しは、その操作の検査を受信・再現状態が満たしたことを示します。
全入力での挙動、サーバー状態の原子的な取得、予約キューが空であること、
後からの変更への耐性は証明しません。

## 可読性整理後の運用上の安定性

`39f5f09`の7領域の整理は、MCP・有限イベントエンジン・採用検証のオフライン回帰
404件に合格しています。MCPの明示実行用10件は除外され、Clippyと整形確認も合格しました。
その後のコード・文書照合で古い移行説明を修正しました。実行コードの変更と新しい実機試験は
行っていません。この結果は宣言した契約の確認であり、あらゆる外乱への耐性ではありません。

| 優先・懸念 | 現在の対処 | 残る弱さ |
| --- | --- | --- |
| 1. 作業途中の中断 | 意図・進捗の永続保存、`needs_inspection`、再観測・再計画、サバイバルの封じたcheckpoint | 操作途中のクラッシュ・応答喪失からの自動再開は一般にはできない。取消しはrollbackではない。[仕様](survival-public-construction.md#stops-and-persisted-evidence) |
| 2. 施工中の変更・予約処理 | 新しい状態照合、移動状態の拒否、グループごとの読戻し | 確認と書込みは別処理。サーバー予約キューが空か、他プレイヤーが間に変更したかを事前に保証できない。[仕様](live-operation-readiness-and-recovery.md#current-implementation-boundaries) |
| 3. サバイバルの移動 | 乾いた立方体環境での明示した予測。位置補正・外力・未対応形状では継続を拒否 | 実測のサーバー位置誤差上限・停止応答はない。網羅的な外乱の実機試験は別作業。[仕様](survival-public-construction.md#native-ownership-and-observations) |
| 4. 採掘・仮設撤去 | 旧接続を閉じ、同一アカウントで新規ログインし、周辺と所持品を再確認 | 対応する仮設撤去ごとに復旧する。同一接続での連続採掘は未対応。再接続・読込みのコストと失敗点がある。[仕様](survival-public-construction.md#native-ownership-and-observations) |
| 5. 建築・挙動探索 | 予算付きworker、候補の枝刈り、予算切れ・未確定の明示 | 実際には建てられる形や正しい回路でも、探索・モデルの上限内で確認できないことがある。[建築探索](survival-construction-generation.md)、[モデル](world-execution-context.md) |
| 6. 物理・実機比較の範囲 | 登録した挙動、明示したモデル選択、有限ケースの比較証拠 | 全回路の実機一致・厳密な時刻一致は未確認。サトウキビ飛行例には新しい実機比較がない。[モデル](world-execution-context.md)、[サトウキビ](existing-machine-modification.md) |

これらは運用条件と検証不足であり、すべてが現在故障しているという意味ではありません。
過去の独立observerの準備状態の問題は未解明ですが、通常のbot一体による建築からは依存を
除去済みです。そのobserverを使う試験には準備確認が必要です。
[過去の問題](survival-observer-readiness-prerequisite.md)。

エンティティ、サバイバルでの能動回路施工、チェスト補給、任意地形への対応は未実装機能です。
上の安定性の懸念と分け、対応範囲の表を参照してください。
